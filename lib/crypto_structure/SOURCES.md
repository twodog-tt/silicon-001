# 结构引擎技术来源（crypto_structure）

本目录实现的是**可指名规则的工程化子集**，不是完整「缠论软件」或「Elliott 数浪工作站」。
每条规则在代码注释与 `theory_refs` 字段中可回溯到下列来源。

## 缠论（Chan / 缠中说禅）— 引擎 `chan-ml-v4`

| 优先级 | 内容 | 状态 |
|--------|------|------|
| P0.1 | 笔间距分档 `bi_gap_mode=A\|B\|C`（间隔 1/3/4） | ✅ 默认 B |

| 门禁 | BTC/ETH 结构金样例离线回归 | ✅ `tests/test_crypto_structure_golden.py` |

### 一级来源

1. **《教你炒股票》第 62 课：分型、笔与线段**  
   - 包含、分型、笔（顶底间至少一独立 K → 本引擎 A 档）  
   - 线段至少三笔；特征序列分型破坏（公开复述的标准工程化）

2. **走势中枢定义**  
   - 笔中枢 / 线段中枢：连续三单元重叠  
   - L2 走势：将完整线段视为次级别笔，再跑特征序列→中枢（结构递归）

3. **动力学**  
   - MACD 柱面积作背驰代理；锚点优先更高可用级别

4. **区间套**  
   - 相邻级别观察区间重叠（中枢嵌套 + 买卖点嵌套）  
   - 输出最紧套带；现价是否落入单独标注

### 多级别图构

| 级别 | 含义 |
|------|------|
| L0_bi | 日线笔级别 |
| L0_4h | 4H 笔级别（时间钻取，结构专用） |
| L1_segment | 线段级别 |
| L2_trend | 走势级别（线段再递归） |
| agg_3d / agg_weekly | N 日 OHLC 聚合时间级（聚合后 &lt;30 根则跳过） |

区间套优先配对：`L0_bi × L0_4h`，其次聚合/线段 × 笔。

### 笔间距分档

| mode | 极值 K 之间（不含两端）最少合并 K | 含义 |
|------|----------------------------------|------|
| A | 1 | 62 课最简 |
| B | 3 | 默认工程口径 |
| C | 4 | 更严 |

## 波浪理论（Elliott Wave）— 引擎 `elliott-r123-v2`

见既有 Frost & Prechter R1/R2/R3 与 Fib 指南位说明（`wave.py` / `theory_refs`）。

## 工程原则

- **可复现**：同 OHLC + 同 `bi_gap_mode` → 同输出  
- **可审计**：`theory_refs` + `levels` + `qujiantao` + `bi_gap_mode`  
- **不安排市场**：结构位是观察/失效条件，不是「到位必反」
